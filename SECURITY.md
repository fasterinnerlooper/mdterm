# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in mdterm, please report it responsibly.

**Do not open a public issue.**

Instead, please email the details to the repository owner via GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/fasterinnerlooper/mdterm/security) of this repository.
2. Click **Report a vulnerability**.
3. Provide a detailed description of the vulnerability.

You should receive an initial response within 7 days. We will work with you to understand and address the issue before any public disclosure.
